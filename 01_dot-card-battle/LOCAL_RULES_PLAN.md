# 大富豪ローカルルール検討履歴

この文書は実装前の検討メモです。日本大富豪連盟のルールを基本とする実装、イレブンバックと階段革命のオプションは `battle-state.js` と `battle.html` に反映しました。現在の動作は README とテストを参照してください。

## 実装前に検討したルール

| ルール | 基本動作 | ジョーカーと組み合わせの論点 |
| --- | --- | --- |
| イレブンバック | J を出すと、その場が流れるまで 3〜2 の強弱を一時反転。革命中は一時的に通常順に戻す。 | J の代用ジョーカーで発動するか、階段中の J で発動するかを決める。ジョーカー自身の最上位は維持。 |
| 8 切り | 8 を含む同ランク組を出すと即座に場を流し、その人から開始。 | 8 の代用ジョーカーで発動可とするか。階段中の 8 は非発動とする実例が多い。 |
| スペードの 3 | 単独のジョーカー 1 枚への切り返しとして出し、即座に場を流す。 | ジョーカー 2 枚組には出せない。スート縛り中も例外にするかを明示。 |
| 革命 | 同ランク 4 枚で 3〜2 の強弱を反転し、次の革命まで継続。 | 4 枚目をジョーカーで代用できるか、ジョーカーだけの組をどう扱うかを明示。発効時点は設定で「出した直後」「場が流れた後」から選ぶ。2〜4 人すべてで 4 枚を必要とするかも決める。 |
| スート縛り | 前の出し方とスート構成が同じなら縛り開始。1 枚出しから有効。場が流れれば解除。 | 複数枚ではスート集合全体を比べる。ジョーカーの仮スートを宣言させるか、ジョーカー入りでは新規縛りを作らないかを決める。 |
| 階段出し | 同スートで連続する 3 枚以上を出す。場の階段と同じ枚数で比較。 | ジョーカーを欠番や端の代用にできる。複数の解釈が成り立つ場合は、代用した数字とスートを確定させる。A-2-3 の循環は認めない方針。 |

## 追加候補

- 5 スキップ、7 渡し、9 リバース、10 捨て、Q ボンバーなどの数字効果。
- 数字縛り、砂嵐などの組み合わせ効果。階段革命は設定で選べるよう実装済み。
- 2・8・ジョーカーなどでの反則上がり。
- 複数ゲームを続ける場合のカード交換、都落ち、大富豪・富豪・貧民・大貧民の順位制度。

これらは地域や実装で細部が異なる。各ルールを独立した ON/OFF 設定にし、ジョーカーを数字・スートの代用にした際の効果、発動順、場が流れた後に残る効果を先に仕様化する。手札の合法手表示と CPU の探索も、その同じ判定器を使う。
